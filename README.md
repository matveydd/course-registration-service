# Сервис регистрации сотрудников на внутренние курсы

Консольное приложение для подачи заявок на внутренние курсы компании, их
рассмотрения и фиксации результатов обучения.

## Возможности
- создание курсов;
- просмотр и поиск курсов по названию;
- подача заявки на курс с проверкой свободных мест;
- рассмотрение заявки (одобрение или отклонение с указанием причины);
- отмена заявки;
- фиксация результата прохождения курса (баллы);
- просмотр своих заявок и результатов.

## Структура проекта
- `main.py` — точка запуска и меню приложения;
- `courses.py` — работа с курсами;
- `applications.py` — работа с заявками;
- `results.py` — работа с результатами;
- `employees.py` — работа с сотрудниками;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных
Данные хранятся в каталоге `data/` в формате JSON:
- `courses.json` — словарь курсов (ключ — идентификатор курса);
- `applications.json` — список заявок;
- `results.json` — список результатов;
- `employees.json` — словарь сотрудников (ключ — идентификатор сотрудника).

## Требования
- Python 3.14;
- pytest;
- flake8.

Установка зависимостей:

```
pip install -r requirements.txt
```

## Запуск программы

```
python main.py
```

## Запуск тестов

```
pytest
```

## Проверка качества кода
