# Сервис регистрации сотрудников на внутренние курсы

## Назначение
Сервис для подачи и обработки заявок сотрудников на участие во внутренних учебных курсах компании: учёт лимита мест, согласование заявок и фиксация результатов обучения.

## Целевая аудитория
Сотрудники компании, подающие заявки на курсы, и кураторы, согласующие заявки и фиксирующие результаты обучения.

## Предметная область
Внутреннее корпоративное обучение.

## Основные сущности
- Сотрудник
- Курс
- Заявка
- Результат

## Основные функции
- Просмотр сведений о курсе
- Проверка наличия свободных мест на курсе
- Формирование статуса заявки сотрудника
- Оценка результата прохождения курса по баллам

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
